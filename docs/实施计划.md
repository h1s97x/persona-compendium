## 技术要点

### Next.js 14 App Router
- 使用 Server Components 提升性能
- 客户端组件用 `'use client'` 标记
- 使用 `loading.tsx` 和 `error.tsx`

### Tailwind CSS 配置
```javascript
// tailwind.config.ts
theme: {
  extend: {
    colors: {
      p5r: {
        red: '#E60012',
        black: '#000000',
        white: '#FFFFFF',
      }
    }
  }
}
```

### Framer Motion 动画
- 页面过渡：`AnimatePresence`
- 元素动画：`motion.div`
- 滚动动画：`useScroll` + `useTransform`

## 开发规范

### 代码规范
- 使用 TypeScript 严格模式
- 组件使用函数式组件
- Props 定义接口类型
- 使用 ESLint + Prettier

### 命名规范
- 组件：PascalCase（`CharacterCard.tsx`）
- 函数：camelCase（`getCharacterById`）
- 常量：UPPER_SNAKE_CASE（`API_BASE_URL`）
- 类型：PascalCase（`Character`）

### Git 提交规范
- `feat:` 新功能
- `fix:` 修复 bug
- `docs:` 文档更新
- `style:` 代码格式
- `refactor:` 重构
- `perf:` 性能优化
- `test:` 测试
- `chore:` 构建/工具

## 风险与应对

### 风险1：动画性能问题
- **应对**: 使用 `will-change` CSS 属性，减少重绘

### 风险2：图片加载慢
- **应对**: 使用 Next.js Image 组件，配置 CDN

### 风险3：音频兼容性
- **应对**: 使用 Howler.js 处理跨浏览器兼容
