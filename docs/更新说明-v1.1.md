## 使用说明

### 音频播放器

音频播放器位于页面右下角，支持以下操作：

1. 点击播放/暂停按钮控制音乐
2. 悬停显示音量控制面板
3. 拖动滑块调节音量（0-100%）

**注意**: 需要在 `public/audio/` 目录下放置 `bgm.mp3` 文件

### 粒子背景

粒子背景自动在所有页面显示，可以通过以下方式自定义：

```typescript
// 在 ParticleBackground.tsx 中修改
const particleCount = 50;  // 粒子数量
const speed = 0.5;         // 移动速度
```

### 自定义动画

使用 Framer Motion 添加自定义动画：

```typescript
import { motion } from 'framer-motion';

<motion.div
  initial={{ opacity: 0, y: 20 }}
  animate={{ opacity: 1, y: 0 }}
  transition={{ duration: 0.6 }}
>
  内容
</motion.div>
```

## 已知问题

### 音频相关
- 某些浏览器需要用户交互后才能播放音频
- 移动端浏览器可能有音频播放限制

### 性能相关
- 粒子数量过多可能影响低端设备性能
- 建议在移动端减少粒子数量

## 升级指南

### 从 v1.0 升级到 v1.1

1. 拉取最新代码
2. 安装依赖（已包含在 package.json）
3. 添加音频文件到 `public/audio/bgm.mp3`
4. 运行开发服务器测试

```bash
cd persona-compendium
npm install
npm run dev
```
